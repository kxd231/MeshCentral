# Security policy

This repository is a fork of [MeshCentral](https://github.com/Ylianst/MeshCentral). Among other things it adds the
JavaScript Web-RDP client (`rdp/`), local pins for server updates (`serverupdates.js`) and the default Windows x64 agent
from [kxd231/MeshAgent](https://github.com/kxd231/MeshAgent).

## Supported versions

Only the latest `1.3.1-custom.N` release gets fixes.

## Reporting a vulnerability

Report it privately in this repository: **Security > Report a vulnerability**
(https://github.com/kxd231/MeshCentral/security/advisories/new). Please do not open a public issue.

A problem that also exists in upstream MeshCentral should be reported to its maintainers as well, as described in the
[upstream security policy](https://github.com/Ylianst/MeshCentral/security/policy).
